Policy / effective 28 August 2026

Privacy

Recordings, scores, passage labels, cleanup settings, and exports stay on your device.

What the app stores

The desktop app stores your theme, pack fields, and optional Steward license details in local application storage. Source files stay in memory while you work. We do not receive or retain them.

Demo mode uses memory only. It does not read or change your real project or license storage.

License verification

If you enter a Steward license, the app sends that token to api.sociobot.in at most once per day. The request contains no recording, score, project name, note, or export. Sociobot/Dodo handles checkout as merchant of record.

Website

A checkout return stores your license token in this browser and removes it from the address bar.

The website loads no third-party scripts, fonts, trackers, or advertising. Hosting logs may contain an IP address, request time, path, and user agent. The public GitHub API supplies desktop release links. A service worker caches public files for offline demo reloads.

Your control

Remove local app data through your application storage settings. Delete exported packs like any other local file. Uninstalling the app does not delete files you exported.

Contact

Open privacy questions in the public product repository. Do not attach recordings or license tokens.
